# Practice 6

Список студентов, просмотр информации и изменение имени. При выходе из формы с несохранёнными изменениями появляется подтверждение.

Запуск из папки practice6:

```bash
flutter pub get
flutter run
```

Экраны: Students → Detail → Edit. Save возвращает имя в Detail, Back возвращает на предыдущий экран.

Скриншоты в корне репозитория: screenshot_detail.png и screenshot_dialog.png.
